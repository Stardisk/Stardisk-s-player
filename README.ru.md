# Stardisk's Player

[English](README.md) | **Русский**

Небольшой аудиоплеер для файлов в выбранной папке. Мне не нужна музыкальная библиотека или куча настроек — я просто хочу слушать музыку из текущей папки.

**Основная версия — C++**. Она разрабатывается в ветке `main` и служит базой будущих релизов плеера. В репозитории также сохранены предыдущие версии на twinBASIC и VB6.

## Скачать

[C++ v1.2.0 для Windows x64](https://github.com/Stardisk/Stardisk-s-player/releases/tag/v1.2.0):

- [stardisk.exe](https://github.com/Stardisk/Stardisk-s-player/releases/download/v1.2.0/stardisk.exe) — плеер.
- [reverse.dll](https://github.com/Stardisk/Stardisk-s-player/releases/download/v1.2.0/reverse.dll) — необязательная поддержка реверса. Положите рядом с EXE и перезапустите плеер.

[MIT License](https://github.com/Stardisk/Stardisk-s-player/releases/download/v1.2.0/LICENSE) также приложена к релизу.

Установка не нужна. Разместите файлы в папке с доступом на запись: плеер создаёт там INI с настройками. [Исторический релиз VB6](https://github.com/Stardisk/Stardisk-s-player/releases/tag/StardiskPlayer) остаётся доступен.

| Версия | Исходники | Как создавалась |
| --- | --- | --- |
| C++ — актуальная | [cpp/](cpp/) | Версия twinBASIC, переписанная на современный C++20 с помощью ИИ. |
| twinBASIC | [twinbasic/](twinbasic/) | Преобразована из legacy VB6 без Windows Media Player и затем доработана; частично сделана с помощью вайбкодинга. |

| Legacy VB6 / без WMP | [legacy/vb6_nowmp/](legacy/vb6_nowmp/) | Написана без вайбкодинга. Использует DirectShow, версия проекта 1.1.2. |

## Актуальный плеер на C++

- Windows 10/11 x64, русский интерфейс и Unicode в путях.
- Воспроизведение файлов из выбранной папки, компактный режим и мультимедийные клавиши.
- Переименование, перемещение и удаление файлов; HTTP/HTTPS-потоки.
- Случайный порядок, повтор трека и фрагмента A–B, управление громкостью и скоростью.
- Системные DirectShow и Media Foundation. Доступные форматы зависят от кодеков Windows.
- Для обычного воспроизведения достаточно одного EXE, без установки Visual C++ Redistributable и .NET. Настройки сохраняются рядом с ним.

## Необязательная библиотека реверса

В [reverse/](reverse/) находятся исходники **reverse.dll** — необязательной x64-библиотеки для активации реверса в версиях C++ и twinBASIC. Соберите её командой `.\reverse\build.ps1`, положите DLL рядом с EXE плеера и перезапустите его. Направление переключается через меню «Режим» или ПКМ по Play. Без DLL обычное воспроизведение работает, а пункт реверса скрыт.

Сборка, подключение, API и ограничения описаны в [инструкции библиотеки](reverse/README.ru.md). Готовые DLL исключены из Git; в репозитории хранятся их исходники.

## Сборка из исходников

Установите LLVM-MinGW. Из PowerShell в корне репозитория:

```powershell
.\cpp\build.ps1
```

По умолчанию компилятор ищется в `C:\Program Files\LLVM-MinGW`. Другой путь задаётся параметром `-Toolchain`. Результат — `cpp/stardisk.exe`.

Требования, варианты сборки и тесты описаны в [инструкции C++](cpp/README.ru.md). Node.js и twinBASIC для сборки C++-плеера не нужны.

## Релизы

Релизы плеера собираются из `cpp/` в ветке `main` на выбранном коммите или теге. Готовые EXE размещаются в [GitHub Releases](https://github.com/Stardisk/Stardisk-s-player/releases), а не в исходниках. Существующий релиз VB6 остаётся доступен как историческая версия.

## Автоматическая проверка

[Windows build](https://github.com/Stardisk/Stardisk-s-player/actions/workflows/windows-build.yml) проверяет сгенерированный интерфейс и собирает C++-плеер и DLL реверса при push в `main`, в pull request и при ручном запуске. Используется закреплённый LLVM-MinGW с проверкой SHA-256. Успешный запуск сохраняет артефакт с EXE, DLL, лицензией, сторонними уведомлениями и контрольными суммами. Системные аудиотесты выполняются локально; workflow проверяет сборку и генерацию.

## Предыдущие версии

[Документация twinBASIC](twinbasic/README.ru.md) описывает создание рабочего `.twinproj` из распакованных исходников и выгрузку изменений обратно в Git.

Две папки в `legacy/` сохраняют исходные файлы VB6, их кодировки и ресурсы. Пути вывода сборки в VBP могут требовать изменения на другом компьютере.
